# Abdi Sileshi — Portfolio

Clean personal site for Abdi Sileshi, a full-stack software engineer. Built with Next.js, React, and Tailwind CSS. No third-party analytics or copied scripts from the previous site.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

This app is ready for Vercel. After it is live, point `abdisileshi.dev` at the new deployment.
